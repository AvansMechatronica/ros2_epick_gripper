# Inleiding

**Experimenteel en (nog)ongetest!**

Dit document beschrijft beknopt de installatie en toepassing van een [Robotiq Epick gripper](https://robotiq.com/products/vacuum-grippers#EPick)

:::{note}
De gripper wordt aangesloten op een USB-poort van de computer waarop een ROS2 node draait welke de gripper kan bedienen. De voeding van de gripper wordt aangesloten controller van de UR-Robot.

:::
